# Python Fundamentals & OOP Practice

A comprehensive collection of core Python concepts, exercises, and examples completed during my B.Tech in CSE.

## 📚 Topics Covered

| File | Topic | Description |
| :--- | :--- | :--- |
| `01_print_and_arithmetic.py` | Basic Syntax | Print statements and basic mathematical calculations |
| `02_variables_and_datatypes.py` | Variables & Types | Strings, integers, floats, and booleans |
| `03_operators.py` | Python Operators | Modulo, floor division, and division operators |
| `04_conditionals_grade.py` | Control Flow | `if`, `elif`, `else` grading evaluation |
| `05_loops_for.py` | Loops | `for` loop traversal and `range()` usage |
| `06_strings_and_slicing.py` | Strings | Slicing, indexing, and basic string operations |
| `07_lists_and_methods.py` | Lists | List methods (`append`, `min`, `len`) |
| `08_dictionaries.py` | Dictionaries | Key-value pairs and record manipulation |
| `09_functions.py` | Functions | `def`, default arguments, and return values |
| `10_list_comprehensions.py` | Comprehensions | List comprehensions for clean data generation |
| `11_exception_handling.py` | Error Handling | `try` / `except` blocks for graceful failure |
| `12_file_handling.py` | File I/O | Reading from and writing to files (`output.txt`) |
| `13_oop_classes_and_objects.py` | OOP Concepts | Object-Oriented Programming (Classes & Objects) |
| `14_modules_and_pip.py` | Modules & Packages | Standard modules (`math`) and external packages (`pyjokes`) |

## 📂 Extra Practice
The `extra_practice/` directory contains initial practice files and early code snippets.

## 🚀 Setup & Running Locally
```bash
# Clone the repository
git clone https://github.com/sidhantsingla0-gif/python-fundamental.git
cd python-fundamental

# (Optional) Create and activate virtual environment
python -m venv myenv
# Windows:
myenv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```
